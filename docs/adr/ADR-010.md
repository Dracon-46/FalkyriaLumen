# ADR-010 — Monorepo com pacotes separados

- **Situação:** aceita
- **Data:** 2026-09-18
- **Origem:** DOC-04, seção 4

## Contexto

Equipe pequena, forte acoplamento conceitual entre o esquema canônico, as regras e a API que os expõe.

## Decisão

Um único repositório com pacotes independentes e versionamento conjunto do esquema canônico.

## Alternativas consideradas

Repositórios separados por serviço.

## Consequências

Mudanças no esquema canônico são atômicas e não geram dessincronização entre serviços. O repositório cresce e exige boa configuração de integração contínua seletiva por caminho alterado.
