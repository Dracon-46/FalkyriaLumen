# ADR-005 — PostgreSQL para domínio e formato colunar para análise

- **Situação:** aceita
- **Data:** 2026-09-18
- **Origem:** DOC-04, seção 4

## Contexto

O domínio tem escritas transacionais e relacionamentos ricos; a análise varre bilhões de linhas históricas. Um único banco atenderia mal aos dois perfis.

## Decisão

PostgreSQL para entidades, indícios, contestações e auditoria. Parquet particionado consultado por motor colunar para as camadas silver e gold.

## Alternativas consideradas

Somente PostgreSQL; somente lakehouse; data warehouse gerenciado.

## Consequências

É preciso manter consistência entre os dois mundos. Em troca, consulta analítica não degrada a operação, e o custo de armazenamento analítico cai por ordens de grandeza.
