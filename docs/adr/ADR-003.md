# ADR-003 — Python na ingestão e detecção, TypeScript na API e no portal

- **Situação:** aceita
- **Data:** 2026-09-18
- **Origem:** DOC-04, seção 4

## Contexto

O ecossistema de coleta, extração de documentos e análise estatística é dominado por Python. A equipe já domina Node com arquitetura limpa para construção de API.

## Decisão

Separar por responsabilidade: Python do conector até o indício; TypeScript do indício até o usuário. O contato entre os dois mundos é o banco de domínio e o lakehouse, nunca chamadas diretas.

## Alternativas consideradas

Tudo em Python; tudo em TypeScript.

## Consequências

Duas cadeias de ferramentas para manter. Em troca, cada camada usa o ecossistema onde é mais produtiva, e a fronteira entre elas é um contrato de dados explícito e testável.
