# ADR-001 — Usar PNCP e SICONFI como espinha dorsal, antes de qualquer raspagem municipal

- **Situação:** aceita
- **Data:** 2026-09-18
- **Origem:** DOC-04, seção 4

## Contexto

Cobrir 5.570 municípios por raspagem individual é inviável para uma equipe pequena e produziria milhares de integrações frágeis.

## Decisão

Integrar primeiro as bases federais de envio obrigatório que já concentram dados de praticamente todos os entes, e só então tratar a cauda longa.

## Alternativas consideradas

Começar pelos portais municipais; começar por um estado piloto; comprar base de terceiro.

## Consequências

Cobertura nacional já na fase 1, com poucas integrações. Em contrapartida, o sistema herda as lacunas das bases federais, o que é tratado pelo módulo de conformidade como achado e não como falha.
