# ADR-015 — Fase 0 sem dependências externas de execução

- **Situação:** proposta — tomada durante a Fase 0, aguarda revisão
- **Data:** 2026-09-29
- **Origem:** montagem do monorepo
- **Código:** `pyproject.toml`

## Contexto

A stack planejada (ADR-003, ADR-005, ADR-009) inclui Dagster, DuckDB,
PostgreSQL e OpenSearch. Nenhum deles é necessário para a camada bronze, os
parâmetros legais, a máquina de estados do indício ou o verificador de
vocabulário.

## Decisão

A Fase 0 usa apenas a biblioteca padrão do Python 3.11 (inclusive `tomllib`
para configuração). A única dependência é `pytest`, e só para desenvolvimento.
Cada dependência nova entra junto com a funcionalidade que a exige, e com o
motivo registrado.

## Alternativas consideradas

Instalar a stack completa desde o início.

## Consequências

O núcleo roda e é testado em qualquer máquina com Python, em segundos, sem
infraestrutura. A superfície de ataque é mínima exatamente na parte que guarda
a prova.

O custo é que a integração com a stack definitiva ainda não foi exercitada. O
backend local da camada bronze não é o de produção, e isso está declarado no
próprio módulo.
